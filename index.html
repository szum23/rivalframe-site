The RivalFrame method

Evidence first. Recommendation second.

The point is not to generate a longer PDF. The point is to reduce uncertainty around a real business decision.

01 / SCOPE
Define the decision

We start with the company, category and question — not a generic template.

02 / MAP
Find the right comparison set

Direct competitors, adjacent substitutes and changing category boundaries are separated deliberately.

03 / VERIFY
Link the evidence

Material claims point back to public sources. Facts, estimates and recommendations stay distinct.

04 / DECIDE
Turn signals into moves

Each report ends with prioritized actions, risks and what should be tested next.
